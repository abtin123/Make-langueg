# ساخت و انتشار ۲۸ زبان اپ آبتین‌مپس

منبع اصلی همهٔ متن‌های اپ فایل `lib/core/localization/app_localizations.dart`
(نقشهٔ `fa`) است. فقط فارسی و انگلیسی داخل خود APK می‌آیند؛ ۲۸ زبان دیگر
به‌صورت بسته‌های دانلودی (`.abl`) از یک ریلیز گیت‌هاب بارگذاری می‌شوند.

زبان‌ها (۲۸ تا):
ar, cs, da, de, el, es, fi, fr, he, hi, hu, id, it, ja, ko, nl, no, pl,
pt, ro, ru, sv, th, tr, uk, ur, vi, zh

## چطور بسازم و منتشر کنم

1. این پوشه را همان‌طور که هست به‌عنوان ریشهٔ یک ریپازیتوری گیت‌هاب پوش کن
   (یا داخل ریپازیتوری موجودت جای‌گزین کن).
2. مطمئن شو در تنظیمات ریپو، مسیر
   **Settings → Actions → General → Workflow permissions** روی
   **Read and write permissions** باشد (برای این‌که ورک‌فلو بتواند ریلیز
   بسازد و فایل‌های fa.json/en.json را کامیت کند).
3. برو به تب **Actions**، ورک‌فلوی **«Build & Release Language Packs»** را
   پیدا کن و **Run workflow** را بزن.
4. این ورک‌فلو روی سرورهای گیت‌هاب (که اینترنت دارند) هر ۷۷۳ رشتهٔ فارسی را
   با چند سرویس ترجمهٔ رایگان و عمومی (Google GTX، MyMemory، چند نمونهٔ
   Lingva) به هر ۲۸ زبان ترجمه می‌کند، در قالب `lang_<code>.abl` فشرده
   می‌کند، و خودش یک **GitHub Release** با تگ `langpacks-latest` می‌سازد و
   همهٔ بسته‌ها را رویش آپلود می‌کند — دقیقاً همان چیزی که کد اپ انتظارش را
   دارد.
5. حدود ۲۱ هزار درخواست ترجمه انجام می‌شود؛ بسته به وضعیت سرویس‌های رایگان
   ممکن است ۳۰ دقیقه تا چند ساعت طول بکشد. اگر بعضی زبان‌ها کامل نشدند،
   ورک‌فلو خودش تا ۵ بار تلاش دوباره می‌کند (با کش، یعنی از همان‌جا که
   مانده ادامه می‌دهد)؛ اگر باز هم ناقص ماند، کافی است دوباره
   **Run workflow** را بزنی.
6. بعد از موفقیت، در تب **Releases** ریپو، ریلیز `langpacks-latest` را با
   ۲۸ فایل `.abl` + `manifest.json` می‌بینی — همان لینکی که اپ در زمان اجرا
   برای دانلود بسته‌های زبان استفاده می‌کند.

## اجرای محلی (اختیاری)

```bash
python tool/l10n/build_release.py --dry-run   # فقط تست ساختار، بدون اینترنت
python tool/l10n/build_release.py             # ساخت واقعی (نیاز به اینترنت)
```

خروجی در `tool/l10n/out/` قرار می‌گیرد.
