# آبتین‌مپ — سازندهٔ بسته‌های زبان

این مخزن فقط متن‌های رابط کاربری را بسته‌بندی و منتشر می‌کند. داده‌های نقشه،
نام کشورها، مکان‌ها، خیابان‌ها، POIها و فایل‌های ABM در بسته‌های زبان وجود
ندارند.

فارسی و انگلیسی در خود اپ وجود دارند، نیاز به دانلود ندارند و در تب زبان با
وضعیت «نصب‌شده» نمایش داده می‌شوند. انتخاب هرکدام، همان لحظه کلیدهای رابط را
در اپ اعمال می‌کند.

برای هر زبان اضافه، یک فایل `locales/<code>.json` با تمام کلیدهای
`examples/base_strings.json` قرار دهید. مقدار هر کلید فقط جایگزین متن همان
کلید در رابط می‌شود؛ مانند `settings: تنظیمات` در فارسی و `settings: Settings`
در انگلیسی. سازنده هیچ API ترجمه‌ای صدا نمی‌زند.

## انتشار

از Actions، workflow `build-and-publish-language-packs` را اجرا کنید. سازنده
فقط localeهای کامل را در release با tag `langpacks-latest` منتشر می‌کند:

```text
manifest.json
lang_ar.lpk
lang_de.lpk
...
```

هر رکورد مانیفست لینک مستقیم فایل، نسخه، اندازه، تعداد کلیدها، جهت متن و
SHA-256 دارد. اپ فقط مانیفست schema version 2 با `app_strings: non-map-ui` را
می‌پذیرد و پیش از نصب، فایل فشرده و هش آن را اعتبارسنجی می‌کند.

## به‌روزرسانی کلیدها

بعد از تغییر `app_strings_snapshot.dart`، دستور زیر را اجرا کنید تا کلیدهای
منبع با رابط Flutter همگام شود:

```bash
python scripts/extract_app_strings.py \
  --source app_strings_snapshot.dart \
  --out examples/base_strings.json
```

سازنده هر locale ناقص را نادیده می‌گیرد و تا زمانی که همهٔ کلیدها و
placeholderهایی مانند `{count}` و `{error}` وجود نداشته باشند، آن را منتشر
نمی‌کند.
