# سازنده زبان‌های آبتین مپس

این مخزن سازندهٔ بسته‌های زبان **Abtin Maps** است.

- منبع فعلی پروژه: **۷۷۱ کلید UI** و **۳۰ زبان**.
- فایل `source/abtinmaps_localization_additions.json` کلیدهای جدید پروژه را به منبع ۵۸۵‌کلیدی قدیمی اضافه می‌کند تا چیزی جا نیفتد.
- فقط **مقدار متن** به سرویس ترجمه ارسال می‌شود؛ نام کلیدها هرگز ترجمه نمی‌شوند.
- placeholderهایی مثل `{name}`، `{error}`، `{count}` و `{value}` قبل از ترجمه محافظت و بعد از ترجمه کنترل می‌شوند.
- اگر ترجمه ناقص باشد، workflow متوقف می‌شود و بستهٔ ناقص منتشر نمی‌شود.
- پس از اعتبارسنجی، هر ۳۰ فایل `.abl` به همراه `manifest.json` در Release با تگ `langpacks-latest` منتشر/به‌روزرسانی می‌شوند.
- متن‌های ثابت فارسیِ UI که قبلاً همیشه فارسی می‌ماندند نیز در پروژه به کلیدهای canonical متصل شده‌اند.

نقشه و نام مکان‌های واقعی عمداً بخشی از UI localization نیستند؛ زبان آن‌ها از داده/ارائه‌دهندهٔ نقشه می‌آید.
