# AbtinMaps NO-API Fast Translation Builder

- 28 target languages
- 8 concurrent translation requests
- Retry on temporary failures
- Persistent translation cache
- Persian (`fa`) and English (`en`) are not generated
- Outputs `.abl` plus JSON and `manifest.json`
- No Google Cloud project
- No API key
- No service account

The translator uses the public Google Translate web endpoint, not the Google Cloud Translation API.
